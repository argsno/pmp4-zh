# 01 — Repository baseline (initial commit + `.gitignore`)

**What to build:** A git rollback point before the translation pipeline generates large artifacts, and a `.gitignore` that keeps Python bytecode out of version control. Without this there is no safe place to reset once the ~6 MB of generated output and ~1.2 MB of translation data are written.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] An initial commit exists containing the currently staged content (the EPUB source, the site builder, the translation standards, and the existing English `web/` output).
- [ ] `.gitignore` excludes `__pycache__/` (and `*.pyc`) so generated bytecode is never re-added to the index.
- [ ] After the commit, `git status` is clean apart from intentionally new work, giving a known baseline to reset to.
