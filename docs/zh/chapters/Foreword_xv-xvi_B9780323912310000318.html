前言

Jensen Huang，NVIDIA，美国加利福尼亚州圣克拉拉

本书由两位杰出的计算机科学家、GPU 计算的先驱 Wen-mei 和 David 执笔。Wen-mei W. Hwu、David B. Kirk 与 Izzat El Hajj 合著的《Programming Massively Parallel Processors》第四版，继续为一种新计算模式的创立作出不可估量的贡献。

GPU 计算已成为现代科学不可或缺的工具。本书将教会你如何使用这一工具，并赋予你一件解决最具挑战性问题的超级工具。GPU 计算将化作一台让你看见未来的时光机、一艘载你前往如今已触手可及的新世界的飞船。

解决世界上许多最具影响力的问题都需要计算性能。自有计算机历史以来，架构师们便一直在寻求并行计算技术以提升性能。百倍的性能提升，相当于依赖串行处理的 CPU 十年所取得的进展。尽管并行计算益处巨大，但要创立一种由用户、开发者、厂商和分销商构成良性循环的新计算模式，却是一个令人望而生畏的“先有鸡还是先有蛋”的问题。

经过近三十年，NVIDIA GPU 计算已无处不在，数百万开发者学会了并行编程，其中许多人正是通过本书更早的版本学会的。

GPU 计算正影响着科学与工业的每一个领域，连计算机科学本身也不例外。GPU 的处理速度使深度学习模型得以从数据中学习并执行智能任务，由此掀起了一波从自动驾驶汽车、机器人到合成生物学的发明浪潮。AI 时代已经到来。

AI 甚至正在学习物理学，并开辟了以比以往快一百万倍的速度模拟地球气候的可能性。NVIDIA 正在构建一台名为 Earth-2 的 GPU 超级计算机——地球的数字孪生——并与全球科学界合作，预测今日人类行为在数十年后对气候的影响。

一位生命科学研究者曾对我说：“因为有你的 GPU，我才能在有生之年完成毕生的事业。”所以，无论你是在推进 AI，还是在进行开创性的科学研究，我都希望 GPU 计算能帮助你完成毕生的事业。
