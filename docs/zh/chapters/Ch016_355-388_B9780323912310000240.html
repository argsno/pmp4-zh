本章给出一个关于深度学习的应用案例研究。深度学习是机器学习中新近出现的一个分支，它使用人工神经网络。机器学习已被用于许多应用领域，根据从数据集中获取的经验来训练或调整应用逻辑。要取得良好效果，往往需要用海量数据来进行这类训练。虽然机器学习作为计算机科学的一门学科早已存在，但它最近才在工业界获得大量的实际认可，原因有二。第一个原因是互联网的普及使得海量数据唾手可得。第二个原因是出现了廉价的大规模并行 GPU 计算系统，能够用这些海量数据集有效地训练应用逻辑。我们将从机器学习和深度学习的简要介绍开始，然后更详细地考察最流行的深度学习算法之一：卷积神经网络（CNN）。CNN 的计算与内存访问之比很高，并且具有高度的并行性，这使它们成为 GPU 加速的绝佳对象。我们将首先给出卷积神经网络的一个基本实现。接着展示如何用共享内存改进这个基本实现。然后展示如何把卷积层表述为矩阵乘法，从而可以借助现代 GPU 中高度优化的硬件和软件来加速。

16.1 背景

机器学习这一术语由 IBM 的 Arthur Samuel 于 1959 年提出（Samuel, 1959），它是计算机科学的一个领域，研究如何从数据中学习应用逻辑，而不是设计显式的算法。机器学习最为成功的场合，是那些无法设计显式算法的计算任务；之所以无法设计，多半是因为人们对如何设计这类显式算法掌握的知识不够。也就是说，人们能够给出各种情形下应当发生什么的示例，却给不出对所有可能输入都能据以做出这类决策的一般规则。例如，机器学习推动了自动语音识别、计算机视觉、自然语言处理和推荐系统等应用领域近年来的进步。在这些应用领域中，人们可以提供大量输入示例以及每个输入应当得到的输出，但没有任何算法能够正确处理所有可能的输入。

用机器学习创建出来的应用逻辑，可以按其所执行任务的类型来归类。机器学习的任务种类繁多，这里我们从中列举几种：

  1. 1. 分类：判定一个输入属于 k 个类别中的哪一个。一个例子是物体识别，比如判断照片中显示的是哪一类食物。
  2. 2. 回归：在给定若干输入的情况下预测一个数值。一个例子是预测某只股票在下一个交易日收盘时的价格。
  3. 3. 转录：把非结构化的数据转换成文本形式。一个例子是光学字符识别。
  4. 4. 翻译：把一种语言中的符号序列转换为另一种语言中的符号序列。一个例子是把英语翻译成汉语。
  5. 5. 嵌入：把输入转换为向量，同时保持各实体之间的关系。一个例子是把一个自然语言句子转换成一个多维向量。

关于机器学习各类任务的数学背景与实用解法，已有大量文献，读者可自行参阅。本章的目的是介绍用神经网络方法处理分类任务时所涉及的计算核函数。对这些核函数有具体的理解，将使读者能够理解并开发面向其他机器学习任务的深度学习核函数。因此，本节将详细讨论分类任务，以建立理解神经网络所需的背景知识。从数学上说，分类器是一个函数 f，它把一个输入映射到 k 个类别或标签上：

f:Rn→1,2,…,k

函数 f 由 θ 参数化，它把输入向量 x 映射为数值编码 y，即：

y=f(x,θ)

参数 θ 通常称为模型。它封装了从数据中学到的权重。要说明 θ 的这一定义，最好用一个具体的例子。让我们考虑一种称为感知机的线性分类器（Rosenblatt, 1957）：y=signW·x+b，其中 W 是与 x 等长的权重向量，b 是一个偏置常数。sign 函数在输入为正时返回 1，输入为 0 时返回 0，输入为负时返回 −1。也就是说，sign 函数作为分类器，激活（即最终确定）了把输入值映射到 {−1, 0, 1} 这三个类别的过程；因此它常被称为激活函数。激活函数为感知机中原本是线性的函数引入了非线性。在这个例子中，模型 θ 就是向量 W 与常数 b 的组合。模型的结构是一个 sign 函数，其输入是输入 x 各元素的线性表达式，式中的系数是 W 的各元素，常数是 b。

图 16.1 给出了一个感知机的例子，其中每个输入都是一个二维（2D）向量 (x1,x2)。这个线性感知机的模型 θ 由一个权重向量 (w1,w2) 和一个偏置常数 b 组成。如图 16.1 所示，线性表达式 w1x1+w2·x2+b 在 x1−x2 空间中定义了一条直线，它把该空间切成两部分：一部分中的所有点使该表达式大于零，另一部分中的所有点使该表达式小于零。直线上的所有点则使该表达式等于 0。

直观地看，给定一组 w1,w2 和 b 的取值，我们就能在 (x1,x2) 空间中画出一条直线，如图 16.1 所示。例如，对于模型为 w1,w2=2,3andb=−6 的感知机，只要连接它与 x1 轴的交点 ((−bw1, 0) = (3, 0)) 和与 x2 轴的交点 ((0, −bw2) = (0, 2))，就能轻松画出这条直线。这样画出的直线对应于方程 2x1 + 3x2 − 6 = 0。有了这张图，我们就很容易直观地看出输入点的分类结果：直线上方的任何点（在图 16.1 中显示为蓝点）被分为类别 1，直线上的任何点被分为类别 0，直线下方的任何点（在图 16.1 中显示为橙点）被分为类别 −1。

为一个输入计算类别的过程，通常称为分类器的推理。就感知机而言，我们只需把输入的坐标值代入 y=signW·x+b. 在我们的例子中，如果输入点是 (5, −1)，就可以把它的坐标代入感知机函数来完成推理：

y=sign2*5+3*−1+6=sign(13)=1

因此 (5, −1) 被分为类别 1，也就是说，它属于蓝点。

多层分类器

当存在某种办法画出若干超平面（即二维空间中的直线、三维（3D）空间中的平面），把空间划分成若干区域，从而界定出每一类数据点时，线性分类器就很有用。理想情况下，每一类数据点应当恰好占据一个这样的区域。例如，在一个二维、两类的分类器中，我们需要能够画出一条直线，把一类的点与另一类的点分开。遗憾的是，这并不总是可行。

考虑图 16.2 中的分类器。假设所有输入的坐标都落在 [0, 1] 区间内。该分类器应当把 x1 和 x2 的取值都大于 0.5 的所有点（即落在定义域右上象限中的点）分为类别 1，其余的点分为类别 −1。这个分类器可以用一条直线来近似实现，如图 16.2(A)所示。例如，直线 2x1 + 2x2−3 = 0 就能正确分类大多数点。然而，有些橙色的点，其 x1 和 x2 都大于 0.5，但两者之和小于 1.5，例如 (0.55, 0.65)，就会被错分到类别 −1（蓝色）。这是因为任何一条直线都必然要么切掉右上象限的一部分，要么把定义域其余部分的一块包含进来。没有任何单独一条直线能够正确分类所有可能的输入。

多层感知机（MLP）允许使用多条直线来实现更复杂的分类模式。在多层感知机中，每一层由一个或多个感知机组成。某一层中各感知机的输出，就是下一层中各感知机的输入。一个有趣而有用的性质是：虽然第一层的输入有无穷多种可能取值，但第一层的输出（也就是第二层的输入）只有为数不多的几种可能取值。例如，如果把图 16.1 中的感知机用作第一层，它的输出就只能取 {−1, 0, 1}。

图 16.2(B)给出了一个两层感知机，它能够精确实现所需的分类模式。第一层由两个感知机组成。第一个感知机 y1=sign(x1−0.5) 把 x1 坐标大于 0.5 的所有点分为类别 1，即输出值为 1；其余的点被分为类别 −1 或类别 0。第一层中的第二个分类器 y2=sign(x2−0.5) 把 x2 坐标大于 0.5 的所有点分为类别 1，其余的点被分为类别 −1。

因此第一层的输出 (y1, y2) 只可能是下列九种情形之一：(−1, −1), (−1, 0), (−1,1), (0, −1) (0, 0) (0, 1) (1, −1), (1, 0), (1,1)。也就是说，送入第二层的输入对只有九种可能取值。在这九种可能中，(1, 1) 是特殊的：橙色类别中所有原始输入点都被第一层映射到了 (1, 1)。因此，我们可以在第二层用一个简单的感知机，在 y1-y2 空间中于 (1, 1) 与其余八个可能点之间画一条直线，如图 16.2B 所示。这可以用直线 2y1 + 2y2 − 3 = 0，或与之只有微小差别的许多其他直线来完成。

让我们仍用图 16.2A 中被单层感知机错分的输入 (0.55, 0.65) 来说明。由两层感知机处理时，图 16.2B 中第一层上方的感知机产生 y1=1,，下方的感知机产生 y2=1。基于这些输入值，第二层的感知机产生 z=1，这正是 (0.55, 0.65) 的正确分类。

要注意，两层感知机仍有明显的局限。例如，假设我们需要构建一个感知机来分类图 16.3A 中所示的输入点。橙色输入点的取值会使第二层得到输入值 (−1, −1) 或 (1, 1)。可以看到，在第二层中无法画出单独一条直线来正确分类这些点。我们在图 16.2B 中表明，可以在第二层再加一个感知机，从而增加一条直线。该函数为 z2=sign(−2y1−2y2−3) 或与之只有微小差别的形式。读者应当验证：图 16.3B 中所有蓝点都会被映射到 z1-z2 空间中的 (−1, −1)，而 y1−y2 空间中的 (1, 1) 和 (−1, −1) 则被映射到 z1−z2 空间中的 (1, −1) 和 (−1, 1)。现在我们可以画一条直线 z1+z2+1=0 或与之只有微小差别的直线来正确分类这些点，如图 16.3C 所示。显然，如果需要把输入定义域划分成更多区域，可能就需要更多的层才能完成正确的分类。

图 16.2B 中的第 1 层是全连接层的一个小例子，其中每个输出（i.e.,y1,y2）都是每个输入 (i.e.,x1,x2) 的函数。一般来说，在全连接层中，m 个输出中的每一个都是全部 n 个输入的函数。全连接层的所有权重构成一个 m × n 的权重矩阵 W，其中 m 行中的每一行都是一个权重向量（含 n 个元素），用于作用在输入向量（含 n 个元素）上，以产生 m 个输出中的一个。因此，从全连接层的输入求出全部输出的过程，就是一次矩阵-向量乘法。我们将会看到，全连接层是许多类型的神经网络的核心组成部分，后面还将进一步研究它们的 GPU 实现。

当 m 和 n 变大时，全连接层的代价会变得极其高昂。主要原因在于全连接层需要一个 m × n 的权重矩阵。例如，在图像识别应用中，n 是输入图像的像素数，m 是需要对这些输入像素执行的分类的数目。在这种情况下，对于高分辨率图像，n 达到数百万；而 m 可能是数百甚至更多，取决于需要识别的物体种类的多少。此外，物体在图像中还可能有不同的尺度和朝向，可能需要设置许多分类器来应对这些变化。把全部输入都送给所有这些分类器，既昂贵又很可能造成浪费。

卷积层通过减少每个分类器所取的输入数目、并让各分类器共享同一组权重，来降低全连接层的代价。在卷积层中，每个分类器只取输入图像的一小块，并根据权重对这一小块中的像素做卷积。其输出称为输出特征图，因为输出中的每个像素都是某个分类器的激活结果。让各分类器共享权重，使得卷积层可以拥有大量分类器（即很大的 m 值），而权重数目不会过多。在计算上，这可以实现为一次二维卷积。不过，这种做法实际上是把同一个分类器应用到图像的不同部位。我们可以对同一输入应用不同的权重组，生成多个输出特征图，本章后面会看到这一点。

训练模型

到目前为止，我们一直假定分类器所用的模型参数已经以某种方式给定了。现在我们转向训练，即利用数据来确定模型参数 θ（包括权重 w1,w2 和偏置 b）取值的过程。为简单起见，我们假定采用有监督训练，即用标注了期望输出值的输入数据来确定权重和偏置的取值。人们还发展出了半监督学习、强化学习等其他训练方式，以减少对标注数据的依赖。读者可参阅相关文献，了解在那些情形下如何完成训练。

误差函数

一般来说，训练把模型参数视为未知量，并在给定标注输入数据的条件下求解一个逆问题。在图 16.1 的感知机例子中，每个用于训练的数据点都会标注上它期望的分类结果：−1、0 或 1。训练过程通常先对 w1,w2 和 b 的取值做一个初始猜测，然后对输入数据执行推理并产生分类结果。这些分类结果会与标签进行比较。人们定义一个误差函数（有时也称代价函数）来量化每个数据点的分类结果与其对应标签之间的差异。例如，假设 y 是分类输出的类别，t 是标签，下面就是一个误差函数的例子：

E=(y−t)22

这个误差函数有一个很好的性质：只要 y 与 t 的取值之间存在任何差异（无论正负），误差值总是正的。如果需要把许多输入数据点上的误差累加起来，正的差异和负的差异都会对总和有贡献，而不会互相抵消。当然，也可以把误差定义为差值的绝对值，此外还有许多别的选择。我们将会看到，系数 12 简化了求解模型参数时所涉及的计算。

随机梯度下降

训练过程会试图找到一组模型参数取值，使所有训练数据点上误差函数值之和最小。这可以用随机梯度下降方法来完成：它反复把输入数据集的不同排列送过分类器，让参数取值不断演化，并检查参数取值是否已经收敛，即其取值是否已经稳定、自上一次迭代以来的变化小于某个阈值。一旦参数取值收敛，训练过程即告结束。

轮次

在训练过程的每一次迭代（称为一个轮次）中，训练输入数据集会先被随机打乱（即重新排列），然后再送入分类器。对输入数据的顺序做这种随机化，有助于避免陷入次优解。对每个输入数据元素，把它的分类器输出 y 值与标签数据相比较，得到误差函数值。在我们的感知机例子中，如果某个数据的标签是（类别）1 而分类器输出是（类别）−1，那么用 E=(y−t)22 算出的误差函数值就是 2。如果误差函数值大于某个阈值，就会触发一次反向传播操作来修改参数，从而减小推理误差。

反向传播

反向传播的思路是：从误差函数出发，回过头去审视分类器内部，弄清每个参数是以何种方式对误差函数值产生影响的（LeCun et al., 1990）。如果对某个数据元素而言，某参数的取值增大会使误差函数值增大，我们就应当减小该参数的取值，从而使这个数据点上的误差函数值下降；反之，则应当增大该参数的取值，以减小该数据点上的误差函数值。在数学上，函数值随它的某个输入变量变化而变化的速率和方向，就是该函数对这个变量的偏导数。对感知机而言，在计算误差函数的偏导数时，模型参数和输入数据点都被视为输入变量。因此，对于每一个触发反向传播操作的输入数据元素，反向传播操作都需要求出误差函数对各模型参数的偏导数值。

让我们用感知机 y=signw1x1+w2x2+b 来说明反向传播操作。假设误差函数为 E=(y−t)22，并且反向传播由一个训练输入数据元素 (5, 2) 触发。目标是修改 w1,w2 和 b 的取值，使感知机更有可能把 (5, 2) 分类正确。也就是说，我们需要求出偏导数 ∂E∂w1、∂E∂w2 和 ∂E∂b 的值，以便据此改动 w1,w2 和 b 的取值。

链式法则

可以看到，E 是 y 的函数，而 y 又是 w1,w2 和 b 的函数。因此我们可以用链式法则来求这些偏导数。对于 w1,

∂E∂w1=∂E∂y∂y∂w1

∂E∂y 是直截了当的：

∂E∂y=∂(y−t)22∂y=y−t

然而，我们在∂y∂w1.上面临着一个挑战。请注意，符号函数不是可微函数，因为它在 0 处不连续。为了解决这个问题，机器学习界通常使用符号函数的一个更平滑的版本，该版本在零附近可微，并且在远离 0 的 x 值处接近符号函数的值。这种更平滑版本的一个简单例子是 sigmoid 函数s=1−e−x1+e−x。对于绝对值很大的负 x 值，sigmoid 表达式由e−x项主导，sigmoid 函数值将近似为 −1。对于绝对值很大的正 x 值，e−x项趋于消失，函数值将近似为 1。对于接近 0 的 x 值，函数值从接近 −1 迅速增加到接近 1。因此，sigmoid 函数在行为上非常接近符号函数，并且对所有 x 值都是连续可微的。随着从符号函数改为 sigmoid 函数，感知机变成了y=sigmoidw1x1+w2x2+b。我们可以将∂y∂w1表示为∂sigmoidk∂k∂k∂w1，这是借助链式法则、使用一个中间变量k=w1x1+w2x2+b来实现的。根据微积分运算，∂k∂w1其实就是x1，并且

∂sigmoid(k)∂k=(1−e−k1+e−k)′=(1−e−k)′(11+e−k)+(1−e−k)(11+e−k)′=e−k(11+e−k)+(1−e−k)(−1×(11+e−k)2(−e−k))=2e−k(1+e−k)2

把这些合到一起，我们得到

∂E∂w1=y−t2e−k(1+e−k)2x1

类似地，

∂E∂w2=y−t2e−k(1+e−k)2x2

∂E∂b=y−t2e−k(1+e−k)2

其中

k=w1x1+w2x2+b

不难看出，这三个偏导数的值完全可以由输入数据（x1、x2 和 t）与模型参数的当前取值（w1,w2 和 b). 的组合确定下来。反向传播的最后一步是修改参数的取值。回想一下，函数对某个变量的偏导数给出的是：当该变量改变取值时，函数值变化的方向和速率。若在给定的输入数据与当前参数取值组合下，误差函数对某参数的偏导数为正值，我们就要减小该参数的取值，使误差函数值下降；反之，若误差函数对该变量的偏导数为负值，我们就要增大该参数的取值，同样使误差函数值下降。

学习率

在数值上，对于那些误差函数对其变化更为敏感的参数（也就是误差函数对该参数的偏导数绝对值较大的参数），我们希望做更大的改动。基于这些考虑，我们从每个参数中减去一个与误差函数对该参数偏导数成正比的量。具体做法是：先把偏导数乘以一个常数 ε（在机器学习中称为学习率常数），再从参数值中减去。ε 越大，参数取值演化得越快，因而有可能用更少的迭代次数达到解；但 ε 过大也会增大不稳定的可能性，使参数取值无法收敛到一个解。在我们的感知机例子中，对参数的修改如下：

w1←w1−ε∂E∂w1

w2←w2−ε∂E∂w2

b←b−ε∂E∂b

在本章余下的部分中，我们将在公式和表达式里用一个通用符号 θ 来表示模型参数。也就是说，我们用一个通用表达式来代表上面三个表达式：

θ←θ−ε∂E∂ϴ

读者应当明白，对于这类通用表达式，把其中的 θ 换成任意一个参数，就能把该表达式应用到那个参数上。

小批量

在实践中，由于回溯过程代价相当高，它并不是由推理结果与标签不符的单个数据点触发的。相反，在一个轮次中把输入随机打乱之后，会把它们划分成若干段，称为小批量。训练过程把整个小批量送过推理，并累加它们的误差函数值。如果该小批量的总误差过大，就对这个小批量触发反向传播。在反向传播过程中，会逐一检查小批量中每个数据点的推理结果；若某个结果不正确，就用该数据求出偏导数值，并按上面所述用它们修改模型参数的取值。

训练多层分类器

对于多层分类器，反向传播从最后一层开始，并修改该层中的参数值，如上所述。问题是我们应当如何修改前面各层的参数。请记住，正如我们在最后一层所演示的，我们可以推导出∂E∂θ，这是基于∂E∂y的。一旦我们得到前一层的∂E∂y，我们就具备了计算该层参数修改量所需的全部信息。

一个简单却重要的观察是：前一层的输出同时也是最后一层的输入。因此，前一层的 ∂E∂y 其实就是最后一层的 ∂E∂x。于是关键就在于，在修改完最后一层的参数取值之后，求出该层的 ∂E∂x。正如下面将要看到的，∂E∂x 与 ∂E∂θ 相差不大，即 ∂E∂x=∂E∂y∂y∂x。

∂E∂y 可以直接复用对参数所做的推导。∂y∂x 也相当简单，因为就 y 而言，输入所起的作用与参数相同。我们只需对中间函数 k 关于输入求偏导数即可。对我们的感知机例子，有

∂E∂x1=y−t2e−k(1+e−k)2w1

∂E∂x2=y−t2e−k(1+e−k)2w2

其中 k=w1x1+w2x2+b。在图 16.2B 的感知机例子中，最后一层（第 2 层）的 x1 就是 y1，即第 1 层上方感知机的输出；x2 就是 y2，即第 1 层下方感知机的输出。现在我们可以着手计算前一层中两个感知机的 ∂E∂θ 了。显然，如果层数更多，这个过程还可以继续重复下去。

前馈网络

把一层层分类器连接起来，并把每一层的输出送入下一层，就构成了一个前馈网络。图 16.2B 给出了一个两层前馈网络的例子。我们关于多层感知机（MLP）的推理与训练的全部讨论，都以这一性质为前提。在前馈网络中，较早一层的所有输出都通向后面的一层或多层；不存在从较后层的输出连回较早层输入的连接。因此，反向传播只需从最后一级向后逐级迭代即可，不会因反馈回路而变得复杂。

16.2 卷积神经网络

深度学习方法（LeCun et al., 2015）使用层级化的特征提取器来学习复杂特征。只要训练数据足够多，使系统能够充分训练各层特征提取器的参数，从而自动发现足够数量的相关模式，这类方法就能获得更准确的模式识别结果。有一类深度学习方法比其他方法更容易训练，泛化能力也好得多，它们基于一种称为卷积神经网络（CNN）的特殊前馈网络。

CNN 发明于 20 世纪 80 年代末（LeCun et al., 1998）。到 90 年代初，CNN 已被用于自动语音识别、光学字符识别（OCR）、手写识别和人脸识别（LeCun et al., 1990）。然而，直到 90 年代末，计算机视觉与自动语音识别的主流方法一直建立在精心设计的人工特征之上。当时标注数据的数量还不足以让深度学习系统与人类专家精心打造的识别或分类函数相抗衡。人们普遍认为，要自动构建层数足够多、性能超过人工定义的应用专用特征提取器的层级化特征提取器，在计算上是不可行的。

2006 年前后，一批研究者提出了无监督学习方法，无须标注数据就能构建多层的层级化特征检测器，从而重新点燃了人们对深度前馈网络的兴趣（Hinton et al., 2006，Raina et al., 2009）。这一方法的第一个重要应用是语音识别。这项突破得益于 GPU：它让研究者训练网络的速度比传统 CPU 快十倍。这一进展，加上网上可得的海量媒体数据，使深度学习方法的地位大幅提升。尽管在语音领域取得了成功，CNN 在计算机视觉领域却一直到 2012 年都基本上无人问津。

2012 年，多伦多大学的一组研究者训练了一个大型深度卷积神经网络，用于在 ILSVRC 竞赛中区分 1000 个不同的类别（Krizhevsky et al., 2012）。以当时的标准衡量，这个网络非常庞大：它约有 6000 万个参数和 65 万个神经元，并在来自 ImageNet 数据库的 120 万张高分辨率图像上训练。借助 Alex Krizhevsky 编写的基于 CUDA 的卷积神经网络库（Krizhevsky），该网络在两块 GPU 上仅用一周就完成了训练。这个网络取得了突破性的成绩，以 15.3% 的测试错误率夺冠；相比之下，使用传统计算机视觉算法的第二名队伍错误率为 26.2%。这一成功引发了计算机视觉领域的一场革命，CNN 由此成为计算机视觉、自然语言处理、强化学习以及许多其他传统机器学习领域的主流工具。

本节给出 CNN 推理与训练的串行实现。我们将使用 LeNet-5，这是 20 世纪 80 年代末为数字识别而设计的网络（LeCun et al., 1990）。如图 16.4 所示，LeNet-5 由三类层组成：卷积层、池化层（subsampling layer）和全连接层。这三类层至今仍是当今神经网络的关键组成部分。我们将逐一考察每一类层的逻辑设计和串行实现。网络的输入显示为一幅灰度图像，其中的手写数字表示为 32 × 32 的二维像素阵列。最后一层计算输出，即原始图像属于该网络所要识别的十个类别（数字）中各个类别的概率。

卷积神经网络推理

卷积网络中的计算被组织为一系列层。我们将层的输入和输出称为特征图，或简称为特征。例如，在图 16.4 中，位于网络输入端的 C1 卷积层的计算被组织为从 INPUT 像素数组生成六个输出特征图。为输入特征图生成的输出由像素组成，其中每个像素是通过对前一层（在 C1 的情况下为 INPUT）所产生的特征图像素的一个小的局部块，与一组权重（即第 7 章（卷积）中所定义的卷积滤波器，称为滤波器组）进行卷积而产生的。然后卷积结果被送入一个诸如 sigmoid 的激活函数，以在输出特征图中产生一个输出像素。可以将输出特征图中每个像素的卷积层看作一个感知机，其输入是输入特征图中的像素块。也就是说，每个输出像素的值是所有输入特征图中相应块的卷积结果之和。

图 16.5 给出了一个小的卷积层例子。其中有三幅输入特征图、两幅输出特征图和六个滤波器组。层内不同的输入-输出特征图配对使用不同的滤波器组。由于图 16.5 中有三幅输入特征图和两幅输出特征图，我们需要 3 × 2 = 6 个滤波器组。对于图 16.4 中 LeNet 的 C3 层，有六幅输入特征图和 16 幅输出特征图，因此 C3 中共使用 6 × 16 = 96 个滤波器组。

图 16.5B 更详细地展示了卷积层所做的计算。为简单起见，我们省略了输出像素上的激活函数。图中表明，每幅输出特征图都是所有输入特征图上卷积结果之和。例如，输出特征图 0 左上角的元素（值为 14），就是把各输入特征图中圈出的小块与对应的滤波器组做卷积算出来的：

(1,2,1,1)·(1,1,2,2)+(0,2,0,3)·(1,1,1,1)+(1,2,0,1)·(0,1,1,0)=1+2+2+2+0+2+0+3+0+2+0+0=14

也可以把这三幅输入图看作一幅三维输入特征图，把三个滤波器组看作一个三维滤波器组。这样，每幅输出特征图就只是该三维输入特征图与该三维滤波器组的三维卷积结果。在图 16.5B 中，左边的三个二维滤波器组构成一个三维滤波器组，右边的三个构成第二个三维滤波器组。一般来说，如果一个卷积层有 n 幅输入特征图和 m 幅输出特征图，就要用到 n*m 个不同的二维滤波器组；也可以把这些滤波器组看作 m 个三维滤波器组。虽然图 16.4 中没有画出，LeNet-5 中用到的所有二维滤波器组都是 5×5 的卷积滤波器。

回想第 7 章“卷积”中讲过，要由一幅输入图像和一个卷积滤波器生成卷积输出图像，需要对“幽灵单元”做出某种假设。LeNet-5 的设计没有做这类假设，而是直接把每个维度边缘处的两个元素当作幽灵单元。这使每个维度的尺寸减少四：上边两个、下边两个、左边两个、右边两个。于是可以看到，对 C1 层而言，32 × 32 的 INPUT 图像得到的输出特征图是一幅 28 × 28 的图像。图 16.4 展示了 C1 层中的一个像素是由 INPUT 像素中一个正方形小块（5 × 5，尽管图中未明确画出）生成的，从而说明了这一计算。

我们假设输入特征图存放在一个三维数组 X[C, H, W] 中，其中 C 是输入特征图的数目，H 是每幅输入图的高度，W 是每幅输入图的宽度。也就是说，最高维的索引选出其中一幅特征图（这些特征图常被称为通道），较低两维的索引则选出一幅输入特征图中的某个像素。例如，C1 层的输入特征图存放在 X[1, 32, 32] 中，因为只有一幅输入特征图（图 16.4 中的 INPUT），它在 x 和 y 两个维度上各有 32 个像素。这也体现了这样一个事实：可以把送入某一层的各二维输入特征图整体看作构成了一幅三维输入特征图。

卷积层的输出特征图同样存放在一个三维数组 Y[M, H − K + 1, W − K + 1] 中，其中 M 是输出特征图的数目，K 是每个二维滤波器的高度（也是宽度）。例如，C1 层的输出特征图存放在 Y[6, 28, 28] 中，因为 C1 用 5×5 的滤波器生成六幅输出特征图。滤波器组存放在一个四维数组 W[M, C, K, K] 中。1 共有 M × C 个滤波器组。用输入特征图 X[c,_,_] 计算输出特征图 Y[m,_,_] 时，所使用的是滤波器组 W[m, c,_,_]。回想一下，每幅输出特征图都是所有输入特征图上卷积结果之和。因此，可以把卷积层的前向传播路径看作 M 次三维卷积的集合，其中每次三维卷积都由一个三维滤波器组指定，该滤波器组是 W 的一个 C × K × K 子矩阵。

图 16.6 给出了卷积层前向传播路径的一个串行 C 语言实现。最外层（m）for 循环（第 04–12 行）的每一次迭代生成一幅输出特征图。接下来两层（h 和 w）for 循环（第 05–12 行）的每一次迭代生成当前输出特征图中的一个像素。最内层的三重循环（第 08–11 行）执行输入特征图与三维滤波器组之间的三维卷积。

卷积层的输出特征图通常还要经过一个池化层（subsampling layer，也称 pooling layer）。池化层通过合并像素来缩小图的尺寸。例如，在图 16.4 中，池化层 S2 接收六幅 28 × 28 的输入特征图，生成六幅 14 × 14 的特征图。池化输出特征图中的每个像素都由对应输入特征图中一个 2 × 2 的邻域生成：把这四个像素的值取平均，构成输出特征图中的一个像素。池化层输出的特征图数目与前一层相同，但每幅图的行数和列数都减半。例如，池化层 S2 的输出特征图数目（六幅）与它的输入特征图数目相同，也就是与卷积层 C1 的输出特征图数目相同。

图 16.7 给出了池化层前向传播路径的一个串行 C 语言实现。最外层（m）for 循环（第 02–11 行）的每一次迭代生成一幅输出特征图。接下来两层（h 和 w）for 循环（第 03–11 行）生成当前输出图中的各个像素。最内层的两重 for 循环（第 06–09 行）把邻域内的像素求和。在图 16.4 所示的 LeNet-5 池化例子中，K 等于 2。随后，为每幅输出特征图各加上一个专属于它的偏置值 b[m]，其和再经过一个 sigmoid 激活函数。读者应当看出，每个输出像素都是由一个等价的感知机生成的：它以每幅特征图中的四个输入像素为输入，生成对应输出特征图中的一个像素。ReLU 是另一种常用的激活函数，它是一个简单的非线性滤波器，只让非负值通过：若 X ≥ 0 则 Y = X，否则为 0。

完成我们的示例：卷积层 C3 有 16 个输出特征图，每个都是一幅 10×10 的图像。该层共有 6×16 = 96 个滤波器组，每个滤波器组有 5×5 = 25 个权重。C3 的输出被送入池化层 S4，后者生成 16 个 5×5 的输出特征图。最后，最后一个卷积层 C5 使用 16×120 = 1920 个 5×5 的滤波器组，从其 16 个输入特征图中生成 120 个单像素输出特征。

这些特征图经过全连接层 F6，该层有 84 个输出单元，每个输出都与所有输入全连接。输出计算为权重矩阵 W 与输入向量 X 的乘积，然后加上偏置并经 sigmoid 函数。就 F6 而言，W 是一个 120×84 的矩阵。总之，输出是一个 84 维向量 Y6 = sigmoid(W * X + b)。读者应当认识到，这等价于 84 个感知机，每个感知机将 C5 层生成的所有 120 个单像素 x 值作为输入。全连接层的详细实现留作练习。

最后一级是一个输出层，它使用高斯滤波器生成一个十维向量，对应输入图像中包含十个数字之一的概率。

卷积神经网络的反向传播

CNN 的训练基于随机梯度下降法和 16.1 节（Rumelhart et al., 1986）中讨论的反向传播过程。训练数据集带有“正确答案”的标签。在手写体识别示例中，标签给出图像中正确的字母。标签信息可用于生成最后一级的“正确”输出：十维向量的正确概率值，其中正确数字的概率为 1.0，其余所有数字的概率为 0.0。

对于每幅训练图像，网络的最后一级将损失（误差）函数计算为生成输出概率向量元素值与“正确”输出向量元素值之差。给定一系列训练图像，我们可以从数值上计算损失函数相对于输出向量各元素的梯度。直观地说，它表示当输出向量元素的值发生变化时，损失函数值变化的速率。

反向传播过程首先计算最后一层损失函数的梯度∂E∂y。然后它通过网络的所有层将梯度从最后一层向前一层传播。每一层以∂E∂y（即后一层的∂E∂x）作为关于其输出特征图的梯度输入，并计算其自身的∂E∂x（关于其输入特征图），如图 16.8B 所示。

如果一层具有学习到的参数（“权重”）w，那么该层还会计算其关于权重的损失梯度∂E∂w，如图 16.8A 所示。例如，全连接层表示为 y = w · x。梯度∂E∂y的反向传播由下式给出：

∂E∂x=wT∂E∂yand∂E∂w=∂E∂yxT

该方程可以在逐元素的基础上推导，正如我们对两层感知机示例所做的那样。回想一下，每个全连接层的输出像素是由一个感知机计算得到的，该感知机以输入特征图中的像素作为输入。正如我们在 16.1 节中对 MLP 训练所展示的，∂E∂x是某个输入 x 的以下两项的乘积之和：该输入元素所贡献到的每个输出 y 元素的∂E∂y，以及该 w 值（x 值借以贡献到 y 值）。因为 w 矩阵的每一行将全连接层的所有 x 元素（列）关联到一个 y 元素（行之一），而 w 的每一列（即 w 的 T 行）将所有 y（i.e.,∂E∂y)元素关联回一个 x（即∂E∂x）元素，因为转置交换了行和列的角色。因此矩阵-向量乘法wT∂E∂y得到一个向量，其∂E∂x值对应所有输入 x 元素。

类似地，由于每个 w 元素与一个 x 元素相乘生成一个 y 元素，因此每个 w 元素的∂E∂w可以计算为∂E∂y中的一个元素与一个 x 元素的乘积。因此，∂E∂y（单列矩阵）与xT（单行矩阵）之间的矩阵乘法，得到了由∂E∂w值组成的矩阵，对应全连接层的所有 w 元素。这也可以看作∂E∂y与x向量之间的外积。

现在让我们将注意力转向卷积层的反向传播。我们将从计算∂E∂x开始，它来自∂E∂y，该值最终将用于计算前一层的梯度。梯度∂E∂x关于通道 c、输入 x，表示为与相应 W（m, c）的“反向卷积”之和，该和针对所有 m 层输出：

∂E∂xc,h,w=∑m=0M−1∑p=0K−1∑q=0K−1(∂E∂ym,h−p,w−q*wm,c,k−p,k−q)

通过h−p与w−q索引进行的反向卷积，使得所有输出 y 元素（它们在前向卷积中受到了某个 x 元素的贡献）的梯度，能够通过相同的权重贡献到该 x 元素的梯度。这是因为，在卷积层的前向推理中，x 元素值的任何变化都会乘以这些 w 元素，并通过这些 y 元素贡献到损失函数值的变化。图 16.9 用一个 3×3 滤波器组的小例子展示了索引模式。输出特征图中的九个阴影 y 元素便是那些 y 元素，它们在前向卷积中受到 xh,w 的贡献。例如，输入元素 xh,w 贡献到 yh−2,w−2，通过乘以 w2,2，并贡献到 yh,w，通过乘以 w0,0。因此在反向传播期间，∂E∂xh,w应当从这些九个元素∂E∂y的值中获得贡献，并且该计算等价于与转置滤波器组 wT 的卷积。

请注意，虽然∂E∂x的计算对于将梯度传播到前一层很重要，但∂E∂w的计算对于调整当前层权重值才是关键。

在所有滤波器组元素位置上的∂E∂w值都计算完成后，将更新权重以最小化期望误差，所使用的公式如 16.1 节所示：w ← w − ε* ∂E∂w，其中 ε 为学习率常数。ε 的初始值凭经验设定，并在各轮次中按照用户定义的规则递减。ε 的值在各轮次中递减，以确保权重收敛到最小误差。回想一下，调整项的负号使得变化方向与梯度方向相反，从而变化可能会减小误差。还要回想，各层的权重值决定了输入在网络中如何被变换。调整所有层的这些权重值会使网络的行为自适应。也就是说，网络从一系列带标签的训练数据中“学习”，并通过针对那些推理结果不正确并触发了反向传播的输入，调整其所有层的所有权重值，从而使自身行为自适应。

16.3 卷积层：一个 CUDA 推理核函数

训练卷积神经网络（CNN）的计算模式类似于矩阵乘法：它既计算密集又高度并行。我们可以并行地处理小批量中不同的样本、同一样本不同的输出特征图，以及每个输出特征图不同的元素。在图 16.12 中，n 循环（第 04 行，遍历小批量中的样本）、m 循环（第 05 行，遍历输出特征图）以及嵌套的 h-w 循环（第 06–07 行，遍历每个输出特征图的像素）都是并行循环，因为它们的迭代可以并行执行。这四个循环层级共同提供了大规模的并行度。

最内层的三个循环层级，即 c 循环（遍历输入特征图或通道）和嵌套的 p-q 循环（遍历滤波器组中的权重），也提供了相当程度的并行性。然而，要将它们并行化，在对 Y 元素的累加中需要使用原子操作，因为这些循环层级的不同迭代可能在同一 Y 元素上执行读-改-写。因此，除非确实还需要更多并行性，否则我们将保持这些循环串行。

假设我们利用卷积层中四个层级的“易并行”部分（n、m、h、w），则并行迭代的总数为 N*M*H_out*W_out 的乘积。这种高度可用的并行性使得卷积层成为 GPU 加速的绝佳候选。我们可以轻松地设计一个具有线程组织的核函数，以捕获这种并行性。

我们首先需要就线程组织做出一些高层的设计决策。假设让每个线程计算一个输出特征图中的一个元素。我们将使用二维线程块，其中每个线程块计算一个输出特征图中 TILE_WIDTH×TILE_WIDTH 像素的一个瓦片。例如，如果设 TILE_WIDTH = 16，那么每个块将共有 256 个线程。这捕获了处理每个输出特征图像素时嵌套 h-w 循环层级并行性的一部分。

线程块可以以几种不同的方式组织成三维网格。每一种方案都指定网格的维度，以不同组合来捕获 n、m 以及 h-w 的并行性。我们将详细介绍其中一种方案的细节，并将其余不同方案以及评估各方案潜在的优缺点留作练习。我们详细给出的方案如下：

  1. 1. 第一个维度（X）对应于每个线程块所覆盖的（M）个输出特征图。
  2. 2. 第二个维度（Y）反映了一个线程块的输出分块在输出特征图中的位置。
  3. 3. 网格中的第三个维度（Z）对应于小批量中的样本（N）。

图 16.13 展示了基于上述线程组织启动核函数的主机代码。网格 X 和 Z 维度上的线程块数量是很直接的：它们分别是 M（输出特征图的数量）和 N（小批量中样本的数量）。Y 维度上的安排则稍微复杂一些，如图 16.14 所示。理想情况下，为了简单起见，我们希望将网格索引的两个维度专用于垂直和水平分块索引。然而，由于我们用 X 表示输出特征图索引、用 Z 表示小批量中的样本索引，我们只有一个维度可用。因此，我们将分块索引线性化，以同时编码输出特征图分块的水平和垂直分块索引。

在图 16.14 的示例中，每个样本有四个输出特征图（M = 4），每个输出特征图由 2×2 个分块组成（第 02 行中 H_grid = 2，第 03 行中 W_grid = 2），每个分块有 16×16 = 256 个像素。网格组织将每个线程块分配给计算这些分块中的一个。

我们已经将每个输出特征图分配给 X 维度，这体现为 X 维度上的四个线程块，每个对应一个输出特征图。如图 16.14 底部所示，我们将每个输出特征图中的四个分块线性化，并将它们分配给 Y 维度上的线程块。于是分块 (0, 0)、(0, 1)、(1, 0) 和 (1, 1) 按行主序分别映射到 blockIdx.y 值为 0、1、2、3 的线程块。因此 Y 维度上的线程块总数为 4（第 04 行中 T = H_grid*W_grid = 4）。于是我们将在第 06–07 行启动一个 gridDim 为 (4, 4, N) 的网格。

16.4 将卷积层表示为 GEMM

我们可以通过将卷积层表示为一个等价的矩阵乘法操作，然后使用来自 CUDA 线性代数库 cuBLAS 的高效 GEMM（通用矩阵乘法）核函数，来构建更快的卷积层。该方法由 Chellapilla et al. (2006)提出。其核心思想是对输入特征图的像素进行展开和复制，使得计算一个输出特征图像素所需的所有元素都存储为由此生成的矩阵的一列连续数据。这将卷积层的前向操作表述为一次大型矩阵乘法。3

考虑一个小的示例卷积层，它接受 C = 3 个特征图作为输入，每个大小为 3×3，并产生 M = 2 个输出特征（每个大小为 2×2），如图 16.5 所示，并出于方便再次展示在图 16.16 顶部。它使用 M × C = 6 个滤波器组，每个大小为 2×2。该层的矩阵版本将按以下方式构造。

首先，我们将重新排列所有输入像素。由于卷积的结果是在各输入特征上求和的，因此输入特征可以被拼接成一个大矩阵。每个输入特征图成为这个大矩阵中的一段行。如图 16.16 所示，输入特征图 0、1、2 分别成为“输入特征 X_unrolled”矩阵的顶、中、底三段。

进行这样的重排，是为了使结果矩阵的每一列都包含计算一个输出特征元素所需的所有输入值。例如，在图 16.16 中，计算输出特征图 0 的 (0, 0) 处的值所需的所有输入特征像素，都在输入特征图中以圆圈标出：

Y0,0,0=(1,2,1,1)·(1,1,2,2)+(0,2,0,3)·(1,1,1,1)+(1,2,0,1)·(0,1,1,0)=1+2+2+2+0+2+0+3+0+2+0+0=14

其中每个内积的第一项是一个向量，由 x 像素块线性化得到，该像素块在图 16.16 中圆圈标出。第二项是一个向量，由用于卷积的滤波器组线性化得到。在这两种情况下，线性化都采用行主序。同样清楚的是，我们可以将这三个内积重新表述为一个内积：

Y0,0,0=(1,2,1,1,0,2,0,3,1,2,0,1)·(1,1,2,2,1,1,1,1,0,1,1,0)=1+2+2+2+0+2+0+3+0+2+0+0=14

如图 16.16 底部所示，来自滤波器组的拼接向量成为滤波器矩阵的第 0 行，而来自输入特征图的拼接向量成为输入特征图展开矩阵的第 0 列。在矩阵乘法过程中，滤波器组矩阵的行与输入特征矩阵的列将生成输出特征图的一个像素。

请注意，2×12 的滤波器矩阵与 12×8 的输入特征图矩阵之间的矩阵乘法，会产生一个 2×8 的输出特征图矩阵。输出特征图矩阵的顶部是输出特征图 0 的线性化形式，底部是输出特征图 1。两者都已经按行主序排列，因此可以作为下一层的独立输入特征图使用。至于滤波器组，滤波器矩阵的每一行只是原始滤波器组的行主序视图。因此滤波器矩阵只是所有原始滤波器组的拼接。其中不涉及滤波器元素的任何物理重排或重定位。

我们得出一个重要的观察：由于卷积的特性，用于计算输出特征图不同像素的输入特征图像素块彼此重叠。这意味着，在生成展开的输入特征矩阵时，每个输入特征图像素被复制多次。例如，每个 3×3 输入特征图的中心像素被使用四次以计算一个输出特征的四个像素，因此它会被复制四次。每条边上的中间像素被使用两次，因此会被复制两次。每个输入特征图四个角上的四个像素只被使用一次，因此不需要复制。因此，展开的输入特征矩阵段中的像素总数为 4*1 + 2*4 + 1*4 = 16。由于每个原始输入特征图只有九个像素，GEMM 表述在表示输入特征图时带来了 16/9 = 1.8 的展开比。

一般而言，展开的输入特征图矩阵的大小可以由生成每个输出特征图元素所需的输入特征图元素数量推导出来。展开矩阵的高度（即行数）是贡献于每个输出特征图元素的输入特征元素数量，即 C*K*K：每个输出元素是来自每个输入特征图的 K*K 个元素的卷积，共有 C 个输入特征图。在我们的示例中，K 为 2，因为滤波器组是 2×2，且有三个输入特征图。因此展开矩阵的高度应为 3*2*2 = 12，这正好等于图 16.16 所示矩阵的高度。

展开矩阵的宽度（即列数）是每个输出特征图中的元素数量。如果每个输出特征图是一个 H_out×W_out 矩阵，那么展开矩阵的列数就是 H_out*W_out。在我们的示例中，每个输出特征图是一个 2×2 矩阵，因而展开矩阵有四列。请注意，输出特征图的数量 M 并不影响复制，这是因为所有输出特征图都是从同一个展开的输入特征图矩阵计算出来的。

输入特征图的展开比，是展开矩阵的大小与原始输入特征图总大小之比。读者应当验证展开比如下：

C*K*K*H_out*W_outC*H_in*W_in

其中 H_in 和 W_in 分别是每个输入特征图的高度和宽度。在我们的示例中，比值为 (3*2*2*2*2)/(3*3*3) = 16/9。一般而言，如果输入特征图和输出特征图比滤波器组大得多，则展开比将趋近于 K*K。

滤波器组以完全线性化的布局表示为一个滤波器组矩阵，其中每一行包含生成一个输出特征图所需的所有权重值。滤波器组矩阵的高度是输出特征图的数量（M）。计算不同的输出特征图涉及共享同一个展开的输入特征图矩阵。滤波器组矩阵的宽度是生成每个输出特征图元素所需的权重值数量，即 C*K*K。回想一下，将权重值放入滤波器组矩阵时不存在重复。例如，滤波器组矩阵只是图 16.16 中六个滤波器组的拼接排列。

当我们将滤波器组矩阵 W 乘以展开的输入矩阵 X_unrolled 时，输出特征图被计算为一个矩阵 Y，其高度为 M、宽度为 H_out*W_out。也就是说，Y 的每一行都是一个完整的输出特征图。

现在我们来讨论如何在 CUDA 中实现这一算法。让我们先讨论数据布局。我们可以从输入和输出矩阵的布局入手。

  1. 1. 我们假设小批量中的输入特征图样本将以与基础 CUDA 核函数相同的方式提供。它被组织为一个 N×C×H×W 数组，其中 N 是小批量中样本的数量，C 是输入特征图的数量，H 是每个输入特征图的高度，W 是每个输入特征图的宽度。
  2. 2. 正如我们在图 16.16 中所展示的，矩阵乘法会自然地产生一个存储为 M×(H_out*W_out) 数组的输出 Y。这正是原始的基础 CUDA 核函数会产生的输出。
  3. 3. 由于滤波器组矩阵不涉及权重值的重复，我们假设它会提前准备好，并组织为一个 M×C×K2 数组，如图 16.16 所示。

展开的输入特征图矩阵 X_unroll 的准备过程更为复杂。由于每次展开都会使输入的大小最多增加 K2 倍，对于典型的 K 值为 5 或更大的情况，展开比可能会非常大。为小批量中的所有样本输入特征图保留内存的占用可能会大得难以承受。为了减少内存占用，我们将仅为 X_unrolled [C*K*K*H_out*W_out] 分配一个缓冲区。我们将通过对小批量中的样本进行循环来复用这个缓冲区。在每次迭代中，我们将样本输入特征图从原始形式转换为展开矩阵。

图 16.17 展示了一个顺序函数，它通过收集和复制输入特征图 X 的元素来生成 X_unroll 数组。该函数使用了五级循环。最内层的两个 for 循环（w 和 h，第 08–13 行）为每个输出特征图元素放置一个输入特征图元素。接下来两级（p 和 q，第 06–14 行）对 K*K 个滤波器矩阵的每个元素重复该过程。最外层循环对所有输入特征图重复该过程。这种实现在概念上很直接，并且由于循环之间没有施加迭代间的依赖关系，可以相当容易地并行化。此外，最内层循环（w，第 10–13 行）的连续迭代从 X 中某个输入特征图的局部分块读取数据，并写入展开矩阵 X_unroll 中的连续位置（X_unroll 中的同一行）。这应当在 CPU 上带来高效的内存带宽利用率。

现在我们准备设计一个实现输入特征图展开的 CUDA 核函数。每个 CUDA 线程将负责从一个输入特征图为输出特征图的一个元素收集 (K*K) 个输入元素。线程总数为 (C * H_out * W_out)。我们将使用一维线程块，并从线性化的线程索引中提取多维索引。

图 16.18 展示了一个展开核函数的实现。请注意，每个线程将构建一列中 K*K 的一段，如图 16.16 中“输入特征 X_Unrolled”数组里阴影方框所示。每一个这样的段都包含输入特征图 X 在通道 c 上的一个块的所有元素，这些元素是与相应滤波器进行卷积操作以产生输出 Y 的一个元素所必需的。

比较图 16.17 与图 16.18 的循环结构可以看出，图 16.17 中最内层的两个循环层级在图 16.18 中变成了外层循环。这种交换使得收集计算输出元素所需输入元素的工作可以由多个线程并行完成。此外，让每个线程收集生成一个输出所需的、来自某个输入特征图的所有输入特征图元素，会产生合并的内存写入模式。如图 16.16 所示，相邻线程在垂直移动完成各自的段时，会写入 X_unroll 中同一行相邻的元素。对 X 的读取访问模式与此类似，可以通过检查相邻线程的 w_out 值来分析。我们将读取访问模式的详细分析留作练习。

一个重要的高层假设是：我们将输入特征图、滤波器组权重和输出特征图都保留在设备内存中。滤波器组矩阵只准备一次，并存储在设备全局内存中，供所有输入特征图使用。对于小批量中的每个样本，我们启动 unroll_Kernel 来准备一个展开矩阵，并启动一个矩阵乘法核函数，如图 16.16 所概述。

用矩阵乘法实现卷积可以非常高效，因为矩阵乘法在所有硬件平台上都经过了高度优化。矩阵乘法在 GPU 上尤其快，因为它在每次全局内存数据访问的每个字节上执行很多浮点运算，即每字节操作数很高。这个比率随着矩阵变大而增加，这意味着矩阵乘法在小矩阵上效率较低。因此，这种卷积方法在生成为乘法所用的大矩阵时最为有效。

正如我们前面提到的，滤波器组矩阵是一个 M×(C*K*K) 矩阵，而展开的输入特征图矩阵是一个 (C*K*K)×(H_out*W_out) 矩阵。请注意，除了滤波器组矩阵的高度之外，所有维度的大小都取决于卷积参数的乘积，而不是参数本身。虽然单个参数可能很小，但它们的乘积往往很大。例如，在卷积网络的早期层中，C 通常很小，但 H_out 和 W_out 很大；而在网络的末端，C 很大，但 H_out 和 W_out 很小。因此，对于所有层，乘积 C*H_out*W_out 通常都很大。这意味着矩阵的大小对于所有层往往都一致地很大，因此这种方法的性能往往较高。

构成展开的输入特征图矩阵的一个缺点是，它涉及将数据最多复制 K*K 次，这可能需要分配大得难以承受的内存。为了规避这一限制，如图 16.16 所示的那些实现会逐块地具体化 X_unroll 矩阵，例如，通过构造展开的输入特征图矩阵，并对小批量中的每个样本迭代地调用矩阵乘法。然而，这限制了实现中的并行性，并且有时会导致矩阵乘法太小而无法有效利用 GPU 的情况。这种表述的另一个缺点是，它降低了卷积的算术强度，因为除了读取 X 本身之外，还必须写入和读取 X_unroll，这比直接方法需要多得多的内存流量。因此，最高性能的实现在展开算法的实现上有着更为复杂的安排，以在最大化 GPU 利用率的同时将来自 DRAM 的读取降到最低。我们将在下一节介绍 CUDNN 方法时回到这一点。

16.5 CUDNN 库

CUDNN 是一个包含用于实现深度学习原语的优化例程的库。它的设计目标是让深度学习框架更容易利用 GPU。它提供了一个灵活且易用的 C 语言深度学习 API，可整洁地集成到现有的深度学习框架中（例如 Caffe、Tensorflow、Theano、Torch）。该库要求输入和输出数据驻留在 GPU 设备内存中，正如我们在上一节中所讨论的。这一要求与 cuBLAS 类似。

该库是线程安全的，因为其例程可以从不同的主机线程调用。前向和反向路径的卷积例程使用一个共同的、封装了层属性的描述符。张量和滤波器通过不透明描述符访问，并可以灵活地沿每个维度使用任意步长来指定张量布局。CNN 中最重要的计算原语是一种特殊形式的批处理卷积。在本节中，我们描述这种卷积的前向形式。控制这一卷积的 CUDNN 参数列于表 16.1。

卷积有两个输入：

  1. 1. D 是一个四维的 N×C×H×W 张量，其中包含输入数据。4
  2. 2. F 是一个四维的 K×C×R×S 张量，其中包含卷积滤波器。

输入数据数组（张量）D 覆盖小批量中的 N 个样本、每个样本的 C 个输入特征图、每个输入特征图的 H 行以及每个输入特征图的 W 列。滤波器覆盖 K 个输出特征图、C 个输入特征图、每个滤波器组的 R 行以及每个滤波器组的 S 列。输出同样是一个四维张量 O，覆盖小批量中的 N 个样本、K 个输出特征图、每个输出特征图的 P 行以及每个输出特征图的 Q 列，其中 P = f(H; R; u; pad_h)，Q = f(W; S; v; pad_w)，这意味着输出特征图的高度和宽度取决于输入特征图和滤波器组的高度与宽度，以及填充和步长的选择。步长参数 u 和 v 允许用户通过只计算输出像素的一个子集来减少计算负载。填充参数允许用户指定向每个特征图追加多少行或多少列 0 元素，以改善内存对齐和/或向量化执行。

CUDNN（Chetlur et al., 2014）支持多种用于实现卷积层的算法：基于矩阵乘法的 GEMM（Tan et al., 2011）和 Winograd（Lavin & Scott, 2016）、基于 FFT 的（Vasilache et al., 2014）等等。这种基于 GEMM、用矩阵乘法实现卷积的算法，与 16.4 节中给出的方法类似。正如我们在 16.4 节末尾所讨论的，在全局内存中具体化展开的输入特征图矩阵，在全局内存空间和带宽消耗两方面都可能代价高昂。CUDNN 通过将展开的输入特征图矩阵 X_unroll 惰性生成并仅加载到片上内存中，而不是在调用矩阵乘法例程之前将其收集到片外内存中，从而避免了这一问题。NVIDIA 提供了一个基于矩阵乘法的例程，能够在 GPU 上高度利用最大理论浮点吞吐量。该例程的算法与 Tan et al. (2011)所描述的算法类似。输入矩阵 A 和 B 的固定大小子矩阵被依次读入片上内存，然后用于计算输出矩阵 C 的一个子矩阵。卷积所带来的所有索引复杂性，都在这个例程的分块管理中得到处理。我们在 A 和 B 的分块上进行计算，同时将 A 和 B 的下一个分块从片外内存取到片上缓存及其他内存中。这一技术隐藏了与数据传输相关的内存延迟，使得矩阵乘法计算只受执行算术运算所需时间的限制。

由于矩阵乘法例程所需的分块划分与卷积的任何参数无关，X_unroll 的分块边界与卷积问题之间的映射并非易事。因此，CUDNN 方法需要计算这一映射，并利用它将 A 和 B 的正确元素加载到片上内存中。这是随着计算推进动态进行的，这使得 CUDNN 的卷积实现能够利用针对矩阵乘法的优化基础设施。与矩阵乘法相比，它需要额外的索引算术，但它充分利用了矩阵乘法的计算引擎来完成工作。计算完成后，CUDNN 执行所需的张量转置，以将结果存储为用户期望的数据布局。

16.6 本章小结

本章以对机器学习的简要介绍开始。随后它更深入地探讨分类任务，并引入了感知机——一种对理解现代 CNN 具有基础意义的线性分类器。我们讨论了前向推理和反向传播训练过程在单层网络和多层感知机（MLP）中是如何实现的。特别是，我们讨论了可微激活函数的必要性，以及模型参数在训练过程中如何通过一个多层感知机网络中的链式法则进行更新。

在了对感知机的概念性和数学性理解的基础上，我们介绍了一个基础的卷积神经网络（CNN）及其主要类型层的实现。这些层可以看作感知机的特例和/或简单适配。接着，我们基于第 7 章（卷积）中的卷积模式，给出了卷积层——CNN 中计算最密集的层——的一个 CUDA 核函数实现。

接着，我们介绍了通过将输入特征图展开为矩阵，从而将卷积层表述为矩阵乘法的技术。这一转换使卷积层能够受益于针对 GPU 的高度优化的 GEMM 库。我们还介绍了针对输入矩阵的展开过程的 C 与 CUDA 实现，并讨论了展开方法的优缺点。

我们以对 CUDNN 库的概述结束了本章，该库被大多数深度学习框架所使用。这些框架的用户可以在不自己编写 CUDA 核函数的情况下，受益于高度优化的层实现。
